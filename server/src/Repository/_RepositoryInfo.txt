Cada ficheiro *Repository.ts contêm funções que realizam todas as queries possíveis de fazer à tabela correspondente

os tipos correspondentes à sua tabela estão exportados no ficheiro types/Types.ts



Todos os Select's recebem a chave primária e devolvem a entrada correspondente


Todos os Insert's recebem valores para todos os campos da tablela e criam uma entrada com esses valores


Todos os Update's recebem valores para todos os campos da tablela e atualizam a entrada correspondente, 
para não alterar campos utilizar os valores obtidos no Select


Todos os delete's recebem a chave primária e apagam a entrada correspondente



Os ficheiros possuem queries adicionais para obter várias entradas segundo um filtro específico da query

O formato do filtro e explicado em cada função

Essas queries retornam um array do tipo correspondente
